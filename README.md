# Fariborz Aref · Labs

**Sociology you can run.** Twelve interactive demonstrations in inequality and research methods, published at https://fariborzaref.github.io/.

| Page | Contents |
|---|---|
| `index.html` | Labs home |
| `inequality.html` | Birth lottery, champagne glass, Lorenz curve and Gini, redistribution by welfare regime, Great Divergence |
| `methods.html` | Simpson's paradox, ecological fallacy, confidence intervals, forking paths, between and within, persistence in panels, small-N overfitting |
| `courses.html` | Course catalog |

All files sit at the top level: `labs.css` (design), `labs.js` (shared helpers), `inequality.js` and `methods.js` (the demonstrations).
Data sources are listed at the foot of each lab page and in comments at the top of each demonstration's code.

No build step. GitHub Pages serves the files as they are.

Every demonstration carries a citation line with a copy button. An optional dark reading mode is available from the moon icon in the header.
